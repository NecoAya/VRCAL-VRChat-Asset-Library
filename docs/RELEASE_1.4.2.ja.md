# VRCAL 1.4.2 正式版

2026年11月26日

## 画面の整理

- ページ上部をタイトルと操作ボタンに絞り、重複した説明、装飾用のラベル、固定フッターを整理しました。
- 素材カードでは分類・タグ・状態をまとめ、照合確認と素材詳細では重複した案内を減らしました。
- 作業台、3D プレビュー、ダウンロード、設定などの画面では、余白を使って操作をまとめています。ダウンロードの進捗、操作結果、対応が必要な案内は該当箇所に表示されます。

## カスタム AI プロバイダー

- **設定とバックアップ**の **AI 分類とエラー解説**（AI 分类与报错解释）を開き、プロバイダーで **カスタム**（自定义）を選びます。OpenAI 互換の Chat Completions または Anthropic Messages を選び、提供元が指定する HTTPS API Base URL、モデル ID、API キーを入力します。利用する機能を選び、送信範囲に同意して保存します。
- API は初期状態では無効です。有効にすると、選んだ用途に必要な長さ制限付きのテキストと認証情報が、入力したアドレスに送信されます。キーは暗号化して保存され、アドレスとプロトコルに紐づきます。どちらかを変更した場合は、キーを再入力し、送信範囲に再同意してください。
- API の動作、モデルの利用権限、料金、データの保存条件は提供元によって異なります。利用するサービスで互換性を確認してください。

カスタム AI プロバイダー機能は NoSetViolin の貢献です。[PR #5](https://github.com/NecoAya/VRCAL-VRChat-Asset-Library/pull/5)

## ダウンロードと更新

ライブラリをバックアップし、旧版を終了してから更新します。既存のライブラリを引き継げます。保存先の指定を求められたら、既存の `VRChatAssetLibrary` の親フォルダーを選んでください。

- 単体ファイル版は `VRC-Asset-Library-1.4.2-x64.exe` を起動します。公式の単体ファイル版は **設定とバックアップ → アプリの更新**から正式版の更新を確認できます。
- フォルダー版は `VRC-Asset-Library-1.4.2-x64-Folder.zip` をすべて展開し、展開先の `VRC素材库.exe` を起動します。次回からもリリースページで手動で更新します。
