# VRC 素材ライブラリ 1.4.1

**現在の正式版は 1.4.1 です。** [リリースとダウンロード](https://github.com/NecoAya/VRCAL-VRChat-Asset-Library/releases/tag/v1.4.1) · [1.4.1 の更新内容と制限](RELEASE_1.4.1.ja.md)。以下は本版の操作手順です。新しい機能の一部のボタンと説明は中国語のままです。従来の日本語表示は引き続き利用できます。詳細な機能ガイドは現在中国語で提供しています。

単体ファイル版は `VRC-Asset-Library-1.4.1-x64.exe` を起動します。フォルダー版は `VRC-Asset-Library-1.4.1-x64-Folder.zip` をすべて展開してから、その中の `VRC素材库.exe` を起動し、同じフォルダー内のファイル一式を保持してください。単体ファイルの正式版 EXE は安定版の更新を確認できます。フォルダー版はリリースページから手動で更新します。`Source.zip` と GitHub の Source code は開発用ソース、Guide／Offline ZIP は説明資料であり、アプリ本体ではありません。

更新前にライブラリの整理情報をバックアップし、旧版を終了してください。既存のライブラリを引き継ぎ、保存先を尋ねられた場合は既存の `VRChatAssetLibrary` フォルダーの親を選びます。**更新履歴**で実行中の版を確認できます。以前の 1.9.x・1.10.x は番号の大きいテスト版のため、1.4.1 へは手動で更新してください。以前の公開プレビューも手動ダウンロードでした。旧テスト版の実行ファイルは公開を終了し、ソースの履歴は残しています。

VRChat 素材を整理する Windows x64 向けローカルアプリです。閲覧とスキャンは読み取り専用です。明示的にインポートした場合のみ、選択した Unity プロジェクトに書き込みます。削除を確認すると、選択した元素材を Windows のゴミ箱に移動します。

1. 旧版を閉じて、上記の 1.4.1 アプリを起動します。既存の保存先を引き続き使用できます。初回は、素材フォルダーの外かつ C ドライブ以外にライブラリの保存先を選びます。
2. 言語選択で **日本語** を選びます。テーマでは **X ライト**、X ダーク、NASA パンク、スイス国際様式を選択できます。設定はすぐに保存されます。素材名、作者名、自分で付けたタグやメモは翻訳・変更しません。
3. **設定とバックアップ** で素材の親フォルダーを追加します。分類用の子フォルダーも再帰的に読み込みます。登録済みの子フォルダーを含む親を追加すると、登録先を親にまとめます。Unity プロジェクトは一つの項目として扱います。
4. **設定とバックアップ → 素材位置**（素材の保存場所）で、複数のパスにチェックを付けるか **全选**（すべて選択）を押し、**移除所选（N）**（選択した登録を解除）を実行します。**取消勾选** は選択を解除するだけです。各行のボタンも引き続き利用できます。この操作は登録の解除であり、元ファイルの削除・移動やゴミ箱への移動は行わず、注釈も保持します。元のパスを再追加すると引き続き使用できます。すべて解除すると一覧は空のままになり、**添加素材文件夹** で自分のフォルダーを追加できます。ライブラリとバックアップは読み込み対象の外に保存し、必要なら先に保存先を変更してください。[詳細な手順（中国語）](SOURCE_LOCATIONS.zh-CN.md)。
5. オンライン補完を有効にすると、BOOTH の商品情報や画像を検索します。曖昧な結果は確認が必要です。自動検索で見つからない場合も、内蔵 BOOTH ブラウザーで検索し、商品ページの適用ボタンから関連付けられます。間違えた出典の確定は取り消せます。
6. **設定とバックアップ** で、公式の単体ファイル正式版 EXE は最新の安定版を確認・ダウンロードし、再起動して更新できます。GitHub の SHA-256 で検証します。EXE は素材フォルダーの外に置いてください。フォルダー版は新版を手動でダウンロードしてすべて展開し、旧版を終了してから既存のライブラリで新版を起動します。自動インストールを利用できない場合もリリースページを使用してください。

## ダウンロードと ZIP の展開

百度のダウンロードページで共有内容を読み取り、必要なファイルを選んで **下载所选（N）**（選択したファイルをダウンロード）を実行します。完了したファイルは全体の再スキャンなしで登録されます。**下载记录**（ダウンロード履歴）で同じ素材のモデル ZIP とマテリアル ZIP を選び、**解压所选并入库**（選択した ZIP を展開して登録）を押します。一つの新しい素材フォルダーの中に ZIP ごとのサブフォルダーを作成するため、同名ファイルを上書きしません。結果は **解压记录**（展開履歴）で確認します。

**下载完成后自动解压 ZIP 并入库**（ダウンロード後に ZIP を自動展開して登録）と **解压并入库成功后，将原 ZIP 移至回收站**（展開・登録成功後に元 ZIP をゴミ箱へ移動）は、どちらも初期状態では無効です。元 ZIP を残す場合は後者を無効のままにしてください。有効にした場合も、展開・検証・登録が成功した後だけゴミ箱への移動を試みます。対象は ZIP のみで、Unity へのインポートは行いません。これらの設定は BOOTH のダウンロードや通常のスキャンには適用されません。[詳しい操作と復旧方法（中国語）](DOWNLOADS.zh-CN.md)。

## プロジェクト内ファイルとインポート

プロジェクトを選び「プロジェクト内のファイルを見る」で実際の Assets を閲覧します。商品と未一致のファイルも表示し、右クリックで場所やパスを確認できます。依存パッケージと Unity バージョンは別のタブで表示します。ファイルの存在や名前の一致だけでは、シーンで使われている証明にはなりません。

素材を右クリックして「プロジェクトにインポート」、またはプロジェクト詳細からローカル素材のインポートを開きます。対象プロジェクトと具体的なファイル・対応版を選び、プレビューを確認して実行してください。

- **unitypackage:** 初回は対象の `Assets/VRCALImportBridge/Editor` にオープンソースの Editor ヘルパーを配置します。リクエストと結果は同プロジェクトの `Library/VRCALImportBridge` に保存します。Unity 標準の確認画面で内容を選んでインポートします。バージョンが完全一致するエディターだけ自動起動します。見つからない場合は一致する Unity.exe を選択するか、手動でプロジェクトを開いてください。コンパイルエラーや自動更新の無効化で待機する場合があります。送信済みは完了を意味しません。受け取り前のリクエストはこちらで、受け取り後は Unity の画面でキャンセルします。
- **通常ファイル・フォルダー:** 元の階層と `.meta` を保ち、`Assets/VRCAL_Imports` 内の新規フォルダーにコピーします。既存ファイルは上書きしません。Assets・Packages・パッケージキャッシュの GUID が衝突する場合は停止します。コピー完了は、Unity のコンパイルや依存関係の処理完了とは異なります。
- **ZIP/RAR/7z:** プロジェクトへのインポート前に展開してください。百度のダウンロード ZIP は上記の専用手順で展開できますが、プロジェクトへのインポート機能自体では展開しません。リンク、元素材と対象の重複、処理中の元ファイル変更は拒否します。

履歴は再起動と資料庫の移行後も保持し、成功後は既存のメモや手動関連を残して素材を関連付けます。通常の資料庫バックアップに工程ファイルやヘルパーは含まれません。コピー後の記録保存が一時的に失敗した場合は再実行せず、結果ファイルによる復旧を待ってください。シェーダー・SDK などの不足は Unity で確認してください。

「貢献者とコミュニティ」の「グループチャットに参加」で QQ グループの QR コードを表示し、番号 **1002563035** をコピーできます。おしゃべり・アップデートのリクエスト・不具合報告にご利用ください。QR コードはオフラインでも表示できます。

## 素材を手動で追加する

ツールバーの「素材を手動追加」から素材フォルダーを複数選択するか、エクスプローラーからフォルダー・ZIP・RAR・7z・Unitypackage をドロップします。選択した内容だけを読み取り、同階層やライブラリ全体は再スキャンしません。オンライン取得が有効な場合は、今回の項目だけを補完キューに追加します。

手動パスは再起動やバックアップ復元後も保持されます。再度追加しても既存の出典確認や注釈は維持されます。設定でパスを外しても元ファイルや注釈は削除しません。ライブラリ・バックアップ・ドライブルート・ディレクトリリンクは素材として追加できません。Unity 内部は「プロジェクト内の商品を読み取る」で確認するか、プロジェクト全体を追加してください。元ファイルのコピー・移動・解凍は行いません。


## 1.2.9：照合確認でローカル画像を比較

**設定・バックアップ → 照合確認**で、初期状態では無効の**照合確認にローカル画像を表示**を有効にします。BOOTH 候補の前に「ローカル」と表示した比較専用の画像が出ます。手動で設定した表紙を優先し、次にスキャンで見つかったローカルのプレビュー画像を使用します。オンラインの商品画像をローカル画像の代わりには使いません。

**ローカル画像を見る**は**ローカル画像プレビュー**を拡大表示するだけで、商品の出典の確定・適用・変更は行いません。**ローカル画像プレビューを閉じる**で戻れます。BOOTH 候補は別に確認してください。ローカル画像の記録がなければカードを表示せず、記録済みの画像を読み取れない場合は**ローカル画像を現在表示できません**と表示し、オンラインの商品画像に切り替えません。画像を指定したい場合は素材詳細の**表紙を変更**でローカル画像を選びます。1.2.7 版の図解マニュアルとスクリーンショットは変更しません。

## 1.2.8：Star のお願いとコミュニティ画面の整理

5・10・20・50 回目の起動時に、操作を妨げない小さな案内が左下に表示されます。案内にはプロジェクトの完全な URL（https://github.com/NecoAya/VRCAL-VRChat-Asset-Library）が表示され、選択してコピーできます。**確認して GitHub を開く**を押した場合のみ標準ブラウザーで開き、**また今度**または閉じる操作では開きません。各回の案内は一度だけで、ページを開けなかった場合は再試行できます。50 回目より後の起動では新たな案内はありません。ページを開くだけで Star は付かず、GitHub 上で自分で選べます。スポンサー一覧とオンライン同期・更新・キャッシュ表示は廃止し、貢献者・ソース・フィードバック・コミュニティの入口は引き続き利用できます。

## 1.2.7：照合確認の上部固定

照合確認の右上にある小さなロックボタンは、初期状態では固定解除です。タイトル・検索・フィルター・ダウンロード状況が確認内容と一緒にスクロールします。**上部を固定**を選ぶと上部に表示したままにでき、**上部の固定を解除**で通常のスクロールに戻せます。スクロール後もボタンを操作でき、切り替えても現在の素材の表示位置と確認順序を保持します。

狭いウィンドウや高い表示倍率では、固定部分の高さを確認作業エリアの45%までに抑えます。内容が多い場合は上部だけを個別にスクロールでき、下には候補の表示領域を残します。選択は自動保存され、再起動・ライブラリ移行・バックアップ復元後も引き継がれます。旧ライブラリの初期状態は固定解除です。既存の出典確認・取り消し・元ファイル保護のルールも引き続き適用されます。

**自動照合をスキップ**を目立つ全幅ボタンにしました。従来どおり「手動整理」に移動し、後で整理を続けられます。**ローカル情報とファイル**を展開すると、時刻・完全なパス・統合ファイル・照合の根拠を確認できます。商品 URL や番号は**商品の出典を手入力**を展開して入力します。BOOTH 検索は常に表示します。確認画面では対応タグを表示しなくなりますが、対応情報・表紙・注釈は保持されます。

## 1.2.6：専用ページで非表示の素材を管理

左側の**手動整理**の下にある**非表示の素材**を開きます。件数はカード単位で、統合されたファイルは1件と数えます。**設定とバックアップ**には**非表示の素材を表示**のリンクだけを残し、同じ専用ページへ移動できます。

名前・パスで検索し、元フォルダーを表示したり、統合項目を展開して各ファイルを確認できます。個別の**再表示**、または項目を選んで**選択項目を再表示**を実行します。既存の表紙、メモ、タグなどの注釈は保持されます。

個別・一括削除では、実際のパスを確認してから Windows のゴミ箱に移動します。従来のパス保護も適用されます。キャンセルしても、ファイルの場所や非表示の状態は変わりません。非表示だけでは元ファイルを移動しません。ゴミ箱へ移動した項目は一覧から除かれます。素材の保存先を一覧から削除しても記録は保持され、同じ保存先を再登録すると再び管理できます。以下の旧版の説明は履歴として残しています。現在の非表示管理にはこの専用ページを使用してください。

## 1.2.4：非表示リストと再照合

素材の右クリックまたは詳細から **ライブラリから非表示** を選択します。元ファイル・表紙・注釈は保持されます。**設定 → 非表示の素材** で名前・パスの一覧と検索、個別・一括の再表示が可能です。再スキャン・再起動・バックアップ復元後も非表示の状態を保持します。

**強制的に再照合** で確認済み・手動分類の素材を確認画面に戻せます。以前の出典と情報を保持したまま **この素材を再照合** で候補を検索し、新しい商品は必ず確認後に適用します。任意の閑魚補助検索を有効にすると、商品詳細ページで **この商品を適用** を選択できます。公開情報を取得できない場合はローカルの入力欄に確認済みの商品名を記入します。検索・ログインページは適用できません。出典の変更は取り消せます。検索補助専用で、購入には使用できません。

## 1.2.5：右クリックメニューと一括操作

**設定とバックアップ → 右クリックメニュー**で表示項目を選び、上下に移動し、初期設定に戻せます。設定は再起動・移行・バックアップ後も保持されます。全項目を非表示にしても、設定への固定入口は残ります。

ギャラリーのカードや照合確認の行を選択し、**選択項目を非表示**または**選択項目を削除（ゴミ箱へ移動）**を実行できます。非表示一覧からも個別・一括削除できます。非表示はアプリ内の表示のみを変更します。削除は元ファイルと選択フォルダー内の全ファイルを移動します。確認画面で実際のパスを確認してください。既定のボタンはキャンセルです。統合項目や親子パスの重複は除きます。

処理結果をパスごとの成功・失敗・未処理に分けて表示します。失敗したファイルは元の場所に残し、完全削除に切り替えません。共有スキャンルート、ライブラリ・キャッシュ・セッション、Unity プロジェクト、リンクは保護します。手動追加した独立素材や登録済み BOOTH ダウンロードは検証後に削除できます。

Windows のゴミ箱から元の場所に復元し、素材を更新または再追加すると、既存のカバーと注釈を引き継ぎます。元から非表示の項目は非表示一覧に残ります。ライブラリのバックアップには元ファイルを含まないため、削除ファイルの復元には Windows のゴミ箱をご利用ください。
