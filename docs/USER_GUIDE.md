当前正式版：**1.4.1**。[本版说明](RELEASE_1.4.1.zh-CN.md)：Prefab 只读组合预览与百度下载提示；静态预览不保证适配。

**新增 3D 功能说明：[轻量 3D 预览与角色＋衣服静态组合](MODEL_PREVIEW.zh-CN.md)。** 在素材详情或单项右键菜单点击“3D 预览”，先选择衣服模型，再用“添加角色看上身参考”从本地资料库选择角色及其模型文件。可分别显隐、调整衣服位置与缩放、查看前后侧面；不依赖 Unity，不自动合骨骼、适配体型或修复穿模，不作为 Unity 实际试穿和安装结果。

**[1.4.0 发布与下载入口](https://github.com/NecoAya/VRCAL-VRChat-Asset-Library/releases/tag/v1.4.0)**：下载 `VRC-Asset-Library-1.4.0-x64.exe` 可直接运行；下载 `VRC-Asset-Library-1.4.0-x64-Folder.zip` 则先完整解压，再启动其中的 `VRC素材库.exe`，保留整个目录。单文件 EXE 可检查稳定版更新；解压目录版仍从发布页手动更新。`Source.zip` 和 GitHub 自动生成的 Source code 是开发源码，Guide／Offline ZIP 是文档，都不是程序。

百度 ZIP 合并解压：在百度页面的“下载记录”勾选同一素材的模型包、材质包，点击“解压所选并入库”；结果写入一个新素材目录，各 ZIP 使用独立子目录，不覆盖同名文件。完成后查看“解压记录”或素材库，无需全局扫描。原包默认保留；“下载完成后自动解压 ZIP 并入库”与“解压并入库成功后，将原 ZIP 移至回收站”两项首次均关闭。只支持 ZIP，不自动导入 Unity。

正式版保留实验功能的验证边界：3D 仅静态参考，不提供自动试穿、体型适配或穿模修复；真实账号交付、真实角色 MA／SDK 和 AI 效果仍需各自验收。MA 日志建议不代表第三方异常已修复；闲鱼仅读取已加载的官方页面，不提供关闭平台窗口后的独立后台发现。网页 AI 由用户自行登录和发送。

## 正式版与测试版升级

升级前建议备份整理资料，正常退出旧版，再运行 1.4.0。继续使用原资料库和人工标注；如果询问保存位置，请选择原 `VRChatAssetLibrary` 文件夹的上级目录，不要另建空资料库。请在“更新记录”核对当前版本，下载新版后仍打开的旧窗口不会自行变成新版。

1.0.0 是首次正式发布，之前的 1.9.x、1.10.x 都是测试版。编号重新起算，因此这些较大编号的旧测试版不会通过内置更新切换到 1.4.0，请手动下载运行一次。此前的公开预览按其发布页手动获取；1.4.0 单文件正式版后续可检查稳定版更新，解压目录版继续手动更新。旧测试版的程序附件已撤下，源码历史保留。

一个支持简体中文、英语和日语的 Windows 桌面素材管理应用。默认只读索引 `E:\VRChat`。首次启动由用户选择 C 盘之外的资料库位置，在所选上级目录下创建 `VRChatAssetLibrary`；备份位置也独立选择。

## 1.2.9：匹配确认本地图片对照

在“设置与备份 → 匹配确认”勾选“匹配确认中显示本地图片”。此项默认关闭；开启后，有本地图片的素材会在 BOOTH 候选之前显示一张标为“本地”的图片，仅供对照。图片优先使用你在素材详情手动设置的封面，其次使用扫描到的本地预览图，不会用联网获取的商品封面充当本地图片。

点击“查看本地图片”只打开“本地图片预览”大图，点“关闭本地图片预览”即可返回；不会确认、应用或修改商品来源。BOOTH 候选仍按原来的方式用候选封面或“使用此商品”确认。没有本地图片时不显示本地卡片；已有图片无法读取时显示“本地图片暂不可用”，不替换成联网商品图片。可回素材详情“更换封面”选择一张本地图片，再继续对照。

## 资料库兼容与封面

资料库位置会同时记在程序旁和当前 Windows 账户中。首次选择位置后自动重启一次，再加载浏览器和封面。若旧版没有共享位置记录，升级后首次询问位置时请选择原 `VRChatAssetLibrary` 的上级文件夹；无需重新确认商品。已登记的资料库无法读取时不会自动新建空数据库。

## 路径管理、内置更新、语言和 X 亮色

### 添加母目录和移除路径

“设置与备份 → 素材位置 → 添加素材文件夹”可直接选择母目录。程序会递归读取分类子目录中的素材；Unity 工程作为整体，素材包的内部文件不会被拆成大量卡片。如果已添加了多个子目录，再选择它们的母目录，会用母目录替换这些登记路径。

每条路径旁的“移除”只将它移出当前扫描和图库范围；原文件、封面与标注保留。重新添加后可继续使用原标注。可以移除全部路径，再添加自己的目录。

勾选多个位置，或点击“全选”后点击“移除所选（N）”，可一次取消登记；“取消勾选”只清除选择。移除全部位置后列表保持为空，可再用“添加素材文件夹”登记自己的目录。此操作不删除、不改名、不搬动原文件，不将文件移入回收站；旧标注保留，重新添加原位置后可恢复使用。逐步操作见[素材位置管理指南](SOURCE_LOCATIONS.zh-CN.md)。

如果母目录内包含当前资料库或备份保存位置，程序会提示先迁移。请使用“资料库数据 → 更改保存位置”，将资料库放到扫描母目录之外，例如素材在 `F:\vrc改模素材`，资料库可放在 `F:\VRCALData\VRChatAssetLibrary`。备份也选择母目录之外的位置。无需移动原素材。不要只按文件夹名称判断哪些目录可以排除。

### 内置更新

在“设置与备份 → 应用更新”点击“检查更新”。发现新版后，可在程序内下载，查看持续显示的进度和下载量；下载完成会校验 GitHub 发布文件的 SHA-256，再提供“重启并更新”。请先停止扫描、联网补全与下载，然后确认重启。

自动安装适用于官方 Windows x64 单文件免安装 EXE；它只替换当前启动的便携 EXE，不修改资料库与素材。稳定版检查读取最新稳定发布。若程序放在受保护的素材目录内，或文件已变化／包含目录链接，则停止自动安装，可使用“打开发布页面”手动获取新版。解压目录版和开发版从发布页面手动更新。

更新遇到断网、取消或校验失败时，旧程序仍可使用。已有兼容稳定版可先检查更新；旧的大编号测试版、公开预览或无法自动安装的版本，请退出后手动运行新版。

### 界面语言与主题

在界面语言选择框或“设置与备份”中选择 **简体中文 / 日本語 / English**。切换即时生效并单独保存，不修改素材名称、文件路径、作者、人工标签和备注，也不翻译 BOOTH 网页正文。

主题增加 **X 亮色**，使用白底、浅灰面板和蓝色强调。可与任意界面语言组合使用；重启、备份恢复和资料库迁移保留有效选择。

## 商品匹配与升级

- 编号优先：纯 BOOTH 编号、压缩包和版本／副本后缀会先核对对应商品；日期、版本号及编号冲突会保守处理。手动来源可输入 1–12 位合法编号。
- 名称匹配支持作者前缀、作者内部短横线，以及本商品明确列出的英日名称。连写名称仅使用已经核实的作者别名，结果有歧义仍待确认。
- 分类采用人工分类、本商品 BOOTH 最细分类、标题／用途、标签、本地线索的顺序。搜索卡片的商品编号必须完全相同；服装内的 PNG、Textures、Materials 不会把整套衣装变成贴图。详情的“查看名称与分类依据”可查看保存的证据。旧自动记录开启联网后按队列渐进补正，失败保留已有资料。
- 单一素材的同名／编号包装层在刷新扫描后合并为一张卡。原文件、各层路径与成员标注保留；详情与匹配确认里展开本地路径，可右键定位。多商品、编号或作者冲突、工程及目录链接保持独立。

旧版自动待确认条目会在开启联网并恢复补全后按新规则复评；仍有歧义时保留可用候选。完成标记随重启和备份保存，网络失败或暂停不会算作已完成，也不会清空旧候选。人工来源、排除和跳过继续优先。

升级：关闭旧版，运行所选版本的程序，沿用已选择的资料库。需要补齐旧扫描的包装关系时点击“刷新素材”，开启联网后补正旧自动资料；本次下载或解压入库无需为此全局扫描。人工来源、分类、排除和跳过优先。四套主题、彩色封面、Ctrl＋滚轮和稳定的确认顺序继续保留。

原有列表、内容密度、虚拟集合、保存筛选、连续多选、标签合并与别名、标注撤销，以及搜索和匹配依据均保留。浏览与整理时，素材只作引用登记；收藏、集合和截图缓存不改变原素材的位置。

## 四种界面主题

主界面右上角“界面主题”可切换“X 暗色”“X 亮色”“NASA 朋克”和“瑞士国际主义”；“设置与备份”提供四套主题的预览和选择。

主题与语言分别保存。选择任意主题后，重启和更改资料库保存位置时都会保留有效选择；新版备份也保存主题与语言，恢复后不会反复重置主题。

X 暗色使用 `#000000` 纯黑背景、`#16181C` 深灰面板、`#2F3336` 分隔线、`#E7E9EA` 正文、`#71767B` 次要文字和 `#1D9BF0` 蓝色重点。圆角控件、清晰边线和本地 Inter 常规／粗体区分内容与操作。

NASA 朋克使用 `#ECE5D6` 暖灰底色、设备面板与细线接缝、铆钉铭牌、四段复古彩条、小号功能编号、黑白警示斜纹及轻微磨损和手写提醒。主要按钮与重要标记采用 `#D63A2C` 红色，不使用霓虹、全息或大面积渐变。

瑞士国际主义以实际 12 栏模块网格组织界面，大标题与小正文形成对比，使用本地随附的 Inter Regular／Bold 两种字重，内容左对齐；界面配色为黑、米白与 `#DA291C` 红色，用细线和编号区分区块，不加入阴影、渐变、纹理或装饰插画。

四套主题覆盖素材网格／列表、匹配确认、详情、工程素材、BOOTH 本地页面、网络面板、设置与右键菜单。素材封面、匹配候选、详情、悬浮介绍和工程预览均保留图片本色。远程 BOOTH 商品和账户网页保留网站自身样式，商品预览与 BOOTH 浏览器的本地工具栏随主题切换。

主界面和本地浏览器工具栏会在窗口显示前读取已保存的主题与语言，避免先闪出浅色界面再切成暗色。Ctrl+滚轮仍用于原有的整界面缩放，主题、语言、内容密度与缩放分别设置。

可编辑 Figma 设计：[画板一](https://www.figma.com/design/QZxQSGdMgfn5OzSj5IvvcO?node-id=2-30)、[画板二](https://www.figma.com/design/QZxQSGdMgfn5OzSj5IvvcO?node-id=2-202)。画板中的彩色示例封面由合成矢量绘制，用于演示显示效果，没有上传真实素材。

## 来源撤回与 BOOTH 账户

顶部和匹配确认页的“撤回来源”恢复最近一次商品确认前的来源、联网介绍、封面、标签、适配与候选，并取消该来源尚未完成的任务。人工标题、分类、标签、备注、收藏、截图和关联仍保留。来源历史最多保存 50 次，跨重启可用，与“撤销整理”相互独立；按钮绑定具体记录，过期按钮不会撤回较新的确认。原固定批次中的素材会回到原位置，不补入新条目。恢复资料库备份会清除此前的撤回历史。

每行 BOOTH 搜索框可填写商品名、编号或商品网址，打开共用登录会话的内置浏览器。搜索模式的工具栏明确显示当前本地素材，进入有效 BOOTH 商品页后点击“应用此商品”。这是人工确认，无需再次核对名称；页面仍要求网页有效加载，服务器错误页和搜索页不能应用。直接填写来源也属于人工确认，后续结果可撤回。

名称规则能从 `Kaguya,Mizuki,Rurune_Veil_Breeze_v.1.1.unitypackage` 提取 `Veil Breeze`，支持明确的多个前置适配名、后置适配与 `v.1.1` 版本格式。Materialpack 会补充主商品检索线索，仍需确认。`6986518 Lilith Vice` 中编号优先直读；即使外层叫 `d1548`，浅层子目录也提供编号。多个独立包、商品编号或作者冲突不会被自动合并认定为一款。

左侧“BOOTH 账号与下载”提供登录、喜欢的商品、Gift、已购资料库入口，账号内容在应用内浏览器读取。登录由用户在 BOOTH/Pixiv 官方页面完成，包括验证码或账号验证；程序不代为提交密码。Chromium 的持久会话保存在所选资料库的 `booth-session`；临时登录 Cookie 另用 Windows 系统加密保存，最长恢复 30 天，服务器仍可使登录失效。不保存明文密码，也不将 Cookie、验证参数或签名下载网址显示在列表、日志或资料库备份中。“清除登录会话”关闭账户网页并清除本机登录状态，已下载文件和素材标注保留。未实际核对登录状态时不声称已登录。

先在 BOOTH 页面选择 C 盘以外、原素材目录以外的下载保存目录，再在网页点击下载。每个任务保存到新的独立子目录，不覆盖旧文件、不自动解压、执行或导入 Unity。完成后只读登记文件名与有界包内目录，自动进入素材库；能确定当前商品时保留公开商品来源，没有依据时继续按文件名匹配。下载记录包含进度、速度、已接收字节和保存时间，完成后仍可查看、定位和打开已登记素材。文件已保存但登记失败时可“重试导入”；应用关闭导致的未完成下载需回 BOOTH 重新点击。

资料库迁移会复制并校验 BOOTH 会话与下载记录。普通资料库备份只保存整理资料与封面，不包含登录凭证或下载原文件；原下载保存位置仍按路径引用。网页账户浏览、登录及原文件下载与公开信息补全队列分别记录，不将登录表单误算成零上传的补全任务。

## 确认与工程浏览

鞋子、袜子归入“服装”，不再单独设“鞋子”。旧鞋类记录与保存的鞋类筛选映射到服装。自动分类优先核对商品标题、商品类别/标签及明确描述商品自身的说明；补充识别 Cozy Cutie、Meira 等商品对上衣、下装、穿着方式或该衣装的具体说明，修正服装误归饰品或未分类。联网类别仍为“未分类”时继续使用有效的本地类别线索，不用未知结果覆盖本地判断。启动时根据已有缓存自动离线重算自动分类，无需重新联网或扫描原文件。人工分类保持优先，包括用户明确设为“未分类”或“饰品”的记录；未知用途或只有“适用于服装”这类兼容表述时不凭猜测归衣服。

Material、PSD、VT_Material&PSD 和新建文件夹等精确辅助目录名不作为独立商品卡片；旧记录和标注仍在资料库/备份中。扫描穿过这类容器寻找有独立名称的真正素材与工程，不将松散贴图、PSD 或裸辅助材质包拆成商品候选。Material Girl、PSD Mix Pack 等完整商品名称保留；Unity 工程也不会因为名称泛化被隐藏。

匹配确认可按文件修改或首次入库时间升降序排列，设置会保存。文件修改时间来自本地文件，合并条目使用成员最新修改时间，不当作购买或下载时间。确认和跳过仅移除当前条目，本页其余素材不重新排列或自动补行；排序、筛选、翻页及“刷新待确认列表”才重新读取相应批次。

本地信息区及展开后的具体成员支持右键打开所在文件夹、复制原路径。每行可直接填写 BOOTH 商品编号或 HTTPS 网址，点击“读取并采用来源”。“跳过自动匹配”将素材转入左侧“手动归类”，保留原资料并停止自动检索；可手动整理或返回自动匹配。显式手动登记来源仍可读取该指定商品。

选择工程后，详情的“工程内素材”展示已有素材封面、工程目录/Prefab/模型文件的名称线索和人工关联。不同素材同名时标记待核对；这是本地名称核对，不等同于已经证明所有引用依赖或实际使用。扫描仅在 Assets 中进行，有数量、深度和时间上限，跳过链接及缓存；不读取素材正文上传网络，不修改工程。工程文件名改变或新导入后，可点“刷新工程素材”。手动关联会独立保存。

旧版数据库和缓存会复制、校验到新位置，原资料保留。程序旁和当前 Windows 账户的小型位置记录同时保存所选路径；更换程序所在文件夹时可继续找到资料库。实际数据库、封面及浏览会话缓存使用选定位置。

## 源文件保护

所有资料库写入经路径验证。扫描、浏览与联网补全不改动原素材或工程；主动导入及其已启用的 MA 装配会写入选定 Unity 工程，明确确认删除会将所选原素材移入 Windows 系统回收站。百度下载页面的 ZIP 解压操作会另建输出目录；只有用户勾选成功入库后回收原包时，才在解压并入库成功后尝试将对应原 ZIP 移入系统回收站。应用不提供永久删除或任意重命名原素材的操作。目录链接和 Unity 缓存不参与索引。联网补全只发送名称、编号等检索线索，不上传素材内容。

人工分类、标签、备注和封面优先于联网信息。同商品目录、版本和压缩包只合并展示，原始记录、路径和成员标注保留。ZIP 与 Unitypackage 的索引在独立进程内只读解析，有时间、内存和条目上限，可取消。RAR / 7z 使用系统工具只读列目录；不能读取时显示说明。扫描与预览不会自动解压；百度下载的 ZIP 解压由下文的专门操作或默认关闭的自动选项触发，不改变 BOOTH 下载和其他压缩包的行为。Unity 工程仅在主动导入后写入所选内容。独立解析进程不是操作系统权限沙箱，不宣称能完全隔离所有解析器漏洞。

本地适配由文件与包内名称、人工确认建立证据；商品适配单独显示。灰色仅表示没有本地证据，不能当作已验证缺失。Ctrl+滚轮可缩放，设置可重置；悬停卡片显示已有商品介绍和适配摘要。

网络面板统计本应用接收的响应正文，不计请求头、TLS 开销或其他应用流量。补全使用 GET 请求，上传正文为零，素材文件不会上传；这不表示网络协议完全没有发送数据。代理检测只读取当前系统配置，结合小型连接检测与实际下载结果显示状态，不修改系统代理；网站拒绝访问或检测超时不能单独证明代理失联。

默认并发处理 3 个素材，可在下载面板或设置中选择 1–6。BOOTH 及其子域名的请求共享至少三秒的启动间隔；封面 CDN 独立调度。429 冷却与未完成任务随队列保存，同一 URL 在途请求共享，缓存写入保持原子性。
保留最近 100 条读取／下载记录、累计接收正文、观察到的历史最高速度，以及最后一段 60 秒采样。累计量包括失败或中断请求已收到的正文；缓存读取不计入累计，同一共享请求不重复计数。空闲当前速率为零，轨迹在短暂零速收尾后保留，重启后仍可查看。完成记录的平均速度按请求开始到最后一块正文的实测时间计算；历史峰值不会当作当前速度。
每个实际请求显示状态。暂停中止活动请求并保存未完成任务；迁移和恢复会先停止／暂停补全，再等待任务结束与最后保存完成。

## 匹配与确认

文件名商品编号优先于说明中的基础模型与工具链接，按商品编号合并不同语言或店铺网址。全角编号、文件名前端紧接文字的编号及明确标注的短编号可识别，日期线索避免当作商品编号；编号不可用时继续名称搜索。素材文件夹中的浅层目录和归档文件名保留为本地检索线索，多个独立商品编号不会自动认作一款。

名称规则清理版本、适配标签、促销装饰、重复标题和 Windows 副本后缀，保留商品名中有意义的型号和版本差异。`作者_商品名` 的备选检索需要商品页面作者或店铺别名核对后才能自动采用。搜索先对最多 30 个结果排序，再读取相关商品；同名或证据冲突仍进入待确认。人工信息不会被刷新覆盖。

左侧“匹配确认”每页展示 10 个素材，BOOTH 候选商品图按行排列；点 BOOTH 候选封面或“使用此商品”确认。标为“本地”的图片只打开本地预览，不确认来源。“加载本页预览图”只缓存公开商品封面，沿用并发、暂停和缓存机制。确认页和详情的原候选“预览网页”使用应用自带 Chromium，网页与资料库接口隔离。原候选预览只确认最初选择的同一商品，不下载或登录；需要账号或自行检索其他商品时使用新的 BOOTH 浏览器。两个浏览器均不需要安装 Chrome，也不绕过网站验证。

搜索结果区与无结果页推荐区分开，推荐商品不会进入候选。匹配记录注明编号、说明链接、名称或人工确认等依据；排除的候选跨重启记忆，可手动恢复。人工指定的来源优先，组内确认同步到各份本地成员；刷新不会改绑人工来源。商品下架或封面失败会保留已有资料。

新版不自动重试整库旧结果。可选中素材点击“在线补全”，或打开其下拉菜单“重试未匹配”；后者跳过已匹配、缺失文件和工程。卡片重试会覆盖其各份本地成员，保留标注。

## 浏览、搜索与整理

网格和列表共用搜索、多选、右键菜单及详情。内容密度、封面完整显示与界面缩放分别设置；切换视图保留选择，返回原筛选保留浏览位置。Shift 连续选择按当前结果顺序执行；方向键浏览，Ctrl+A 选择当前已显示结果，Ctrl+F 搜索，Esc 清除选择。编辑框与弹窗内不抢用这些快捷键。

集合只保存素材关联，同一素材可加入多个集合；移出或删除集合不删除素材。智能视图保存筛选条件并动态显示结果。标签可设置别名、合并及批量增删；撤销恢复本次标注变更，保留之后的联网信息。关闭后重新打开会保留集合、别名、视图偏好与标注。

搜索使用 SQLite FTS5 和本地字段索引；中文、日文短词、中英混排、文件名、编号、作者、标签及备注都纳入测试。多词默认共同匹配，准确商品编号优先；结果显示命中字段。适配筛选使用本地证据，普通关键词也可搜索商品支持的模型。派生索引可重建，原始记录与人工信息单独保存。异常记录保留原始内容并提示，不静默删除。能确认的同盘外部改名或移动保留记录身份；跨盘复制、多个硬链接等不凭猜测重绑定。

备份包含整理信息、集合、别名、设置、封面和恢复用异常记录，校验通过后才导入；不打包原素材。旧版备份兼容。图像预览范围与正文检索范围有明确限制：本版不提供视觉语义搜索、云端 AI、团队同步或完整工程依赖导出。

## 工程文件与主动导入

选择「工程与成品」里的工程，在详情点「查看工程文件」。这里直接读取该工程 `Assets` 的真实目录与文件，即使它们没有匹配到素材库商品也会显示。可逐层打开文件夹、筛选当前已载入列表、翻页、右键定位或复制路径。「工程依赖」单独展示 `Packages/manifest.json` 声明的包与工程版本。文件存在、名称匹配与手动关联，都不等于已经证明场景正在引用它。

导入入口：素材卡片右键或详情的「导入到工程」，也可在工程详情点「导入本地素材」。选择目标工程和具体文件／适配包，阅读预览后点「导入到所选工程」。目标未预选时需要明确选择；多份包不会替用户选适配版本。可用「选择其他工程文件夹」登记有效的本地 Unity 工程。

- `.unitypackage`：首次主动导入会在目标 `Assets/VRCALImportBridge/Editor` 安装开源 Editor 助手，在 `Library/VRCALImportBridge` 保存请求和回执。助手核对包哈希后调用 Unity 的 `AssetDatabase.ImportPackage(path, true)`，由 Unity 原生窗口确认具体内容。自动启动仅选择与工程完全相同的 Unity 版本；找不到时可选择匹配的 `Unity.exe` 或手动打开工程。工程编译错误、禁用自动刷新或尚未载入助手时，记录会继续等待，不能视为完成。尚未被 Unity 接收的请求可在管理器取消；已接收的请求请在 Unity 窗口取消。
- 普通文件／文件夹：保留文件内容、原目录和 `.meta`，复制到目标 `Assets/VRCAL_Imports` 下的全新目录。先暂存、校验哈希和 GUID，再整体提交；不会覆盖原有文件。工程已有相同 GUID 时停止复制，避免悄悄改变引用。外部本地包或无法完整核对的范围也会阻止复制，可改用 Unity 素材包方式。记录的「复制完成」表示文件已放入，不表示 Unity 编译和依赖处理全部成功。
- 工程导入入口不自动解压 ZIP、RAR、7z。百度下载的 ZIP 可先在下载页面解压并入库；其他压缩包请自行解压并手动添加素材，再选择具体内容。解压入库不等于导入 Unity。源目录与目标工程重叠、目录链接、复制期间源文件改变等情况会阻止导入。

导入记录显示目标、文件数、字节和状态，重启后继续读取回执。成功后自动补充该工程与素材的关联，保留原有备注与手动关联。复制已完成但资料库暂时无法保存时，以工程回执恢复并重试关联，**不要重复导入**。记录随资料库迁移；普通资料库备份不备份工程文件或导入助手，也不是 Unity 工程备份。

浏览与扫描保持只读；确认删除会将原素材移入回收站；**点击导入是仅针对所选目标工程的写入操作**。本版不自动修复缺少的着色器、SDK、脚本依赖，也不替用户选择包内覆盖项。


工程导入隔离验收：`scripts/ui-project-import-test.cjs` 使用合成资料库验证真实界面和复制；`scripts/native-project-import-test.cjs` 仅在显式提供 `VRC_NATIVE_TEST_UNITY` 后创建独立工程，验证实际 Unity 助手接收请求。后台模式无法点击原生确认窗口，因此不把该检查当作完整的交互导入验收。

贡献者与社区 → 加群聊天：显示随程序保存的 QQ 群二维码，支持复制群号 1002563035。欢迎聊天、催更与反馈 Bug；无需联网加载二维码。

## 1.2.1：恢复资料库位置与可选闲鱼搜索

启动时找不到旧资料库，会显示登记的完整路径。可以重试连接磁盘、重新选择包含 library.sqlite 的原资料库文件夹，或确认另一个有效的位置记录。选择原文件夹本身或上级目录均可识别；此流程不创建空库，不移动源资料、不改写数据库，也不自动采用另一份资料库。选定后重启再按正常方式读取。错误也可能来自权限、磁盘空间或外部文件变动，单凭清理回收站后的恢复不能确定根因。

在设置与备份的“辅助搜索”勾选“启用闲鱼搜索”，确认免责声明后，匹配确认页显示“进行闲鱼尝试补全”。关闭后立即隐藏入口并关闭辅助窗口。默认不启动会话、不发闲鱼请求。

点击后用当前素材的名称线索准备关键词，打开独立的官方闲鱼网页。可修改关键词、正常登录，并核对具体商品详情后点“尝试采用此闲鱼来源”，交由原有安全补全流程读取公开标题和封面，支持来源撤回。网站验证、下架或仅客户端可见的信息可能导致补全失败，已有资料保留；这不是绕过登录或抓取私有接口。也可把结果名称整理后交给内置 BOOTH 搜索，平台编号分开处理。

图片工具只在本机读取所选封面、文件或剪贴板图片。网页图搜不可用时，可主动保存副本，到手机 App 手动搜图，不自动上传图片。闲鱼仅作辅助搜索，不可用于购买，不证明正版权利或作者授权。登录会话保存在当前资料库，普通备份不含凭证；恢复备份不会默默启用该功能。


## 手动添加素材与拖拽

点击主界面“手动添加素材”，可多选素材文件夹；也可以直接从资源管理器把文件夹、ZIP、RAR、7z、Unitypackage 等拖入应用。只识别这次选择的内容，不扫描同级目录或重新刷新整个资料库。结果直接出现在图库，联网开启时继续补全本次条目。

已添加的路径会记住，重启或恢复备份后保留。重复拖入沿用原记录与人工标注。设置与备份的“素材位置”标明“手动添加”，移除路径仅停止显示和读取，原文件及标注保留。读取过程可停止；失败详情会列出未添加的路径。

直接拖入完整 Unity 工程会登记为工程。工程内部的 Assets/Packages 内容请通过“读取工程内商品”查看，不作为独立下载包重复索引。添加过程不导入工程、不解压或复制素材。


## 1.2.7：匹配确认顶部锁定

- 进入“匹配确认”，右上角的小锁默认解锁。此时标题、搜索、筛选和下载状态随确认内容一起滚走，为素材确认留出空间。
- 点击“锁定顶部区域”可固定顶部；再点“解锁顶部区域”即可恢复随内容滚动。小锁在滚动后仍可操作，切换保留当前素材位置与确认顺序。
- 窄屏或较高缩放下，锁定顶部最多占匹配工作区高度的45%，内容过多可在顶部内部独立滚动，下方继续显示候选。
- 选择会自动保存，重启、迁移和备份恢复后继续沿用。旧资料库默认解锁；原有匹配确认、来源撤回及原文件保护规则继续适用。

- “跳过自动匹配”使用醒目的整行按钮；点击后转入“手动归类”，可稍后继续整理。按钮含义与原有跳过操作相同。
- 时间、完整路径、本地成员和匹配依据默认收在“本地信息与文件”中，按需展开；商品网址或编号在“手动填写商品来源”中展开输入。BOOTH 搜索保持展开显示。
- 确认页不再展示适配标签，适配资料、封面和人工标注继续保留。

## 1.2.6：独立管理已隐藏素材

- 左侧“手动归类”下方的“已隐藏素材”显示隐藏条目数量，点击进入独立页面；合并文件按一张卡片计数。设置与备份只保留“查看已隐藏素材”跳转入口。
- 在页面顶部按名称或路径搜索；点击“打开所在文件夹”核对原位置，合并条目可展开查看各份文件。
- 点击“恢复显示”恢复单项，或勾选条目后点击“恢复所选”。恢复后沿用原封面、备注、标签和其他人工标注。
- 单项“删除（移入回收站）”和“批量删除（移入回收站）”仍先列出实际路径，并沿用原有路径保护。取消确认不会移动文件或改变隐藏状态。
- 隐藏本身不移动原文件；系统回收站中的素材不会列在此页。来源路径停用后，记录继续保留，重新加入该路径后可继续管理。以下旧版本条目保留历史入口说明；当前隐藏管理入口以本节为准。

## 1.2.4：隐藏名单、强制重新匹配和闲鱼商品应用

- **隐藏**：右键素材或打开详情，选择“从资料库隐藏”。多选后可一次隐藏。只隐藏应用中的条目，同时停止这些条目的匹配任务，不删除、移动或修改原文件，不丢弃封面和人工标注。刷新扫描、重启、迁移和备份恢复都会保留此状态。
- **查看与恢复**：进入“设置与备份 → 已隐藏素材”，查看名称、原路径及合并成员，按名称或路径搜索。点击“恢复显示”，或勾选若干条目后点击“恢复所选”。可以打开原文件夹核对。移除整个素材路径后，该路径的隐藏记录仍保留，重新加入路径后可查看。
- **强制重新匹配**：右键或详情点击“强制重新匹配”，即使曾确认来源、未找到或跳过自动匹配，也会回到匹配确认页。原来源、封面、人工分类、备注、标签和已排除商品保留。点击“重新匹配该素材”再次检索，结果始终等待核对，不自动替换已确认商品。关闭联网时也能先进入确认页，联网后继续处理。
- **闲鱼商品**：设置中启用“闲鱼搜索”并确认提醒，在匹配确认点击“进行闲鱼尝试补全”。进入真正的商品详情页后，顶部“应用此商品”亮起。优先读取当前页面公开的标题、作者和封面；没有可验证资料时，上方填写“商品名称（网页未能读取时手动填写）”后应用当前链接。手填时不会猜测作者或封面。搜索页、登录页或已切换但未加载完成的页面不能应用。
- 新来源仍使用“撤回来源”恢复原商品。网页和登录信息不会保存在匹配任务中，只保留必要的公开商品资料；远程网页没有桌面接口。闲鱼仅作辅助搜索，不可用于购买，最终仍应自行核对原作者及授权。

## 1.2.5：右键菜单、批量隐藏与回收站删除

- 打开“设置与备份 → 右键菜单”，勾选要显示的项目，用“上移 / 下移”调整顺序，或恢复默认。配置立即保存，并随重启、迁移及备份保留。右键菜单末尾始终保留“设置右键菜单”入口；当前素材不适用的操作不会显示。
- 图库勾选多个卡片后，点击“批量隐藏”或“批量删除（移入回收站）”。匹配确认页可逐行选择或选择本页，然后批量操作，不会打乱其余条目的顺序。“已隐藏素材”也支持单项与批量删除。
- **隐藏**只改变本应用的显示，原文件不动；设置中可恢复显示。**删除**会将原素材移动到 Windows 系统回收站，包含选中文件夹内的全部文件。请核对确认窗口列出的实际路径，默认按钮为“取消”。合并卡片的多个路径会分别列出，父子重叠路径只执行一次。
- 删除后按路径显示成功、失败和未处理。失败的文件留在原处，不改用永久删除。部分成功可在处理结果中核对，再选择失败条目重试。
- 共享扫描根、资料库及缓存和会话、Unity 工程及其内部文件、目录链接不能删除；手动添加的独立素材及已登记 BOOTH 下载文件通过检查后可删除。文件过多或层级太深时会拒绝并提示缩小范围。确认期间路径改变会停止处理。
- 删除后保留封面、人工标注与记录。可在 Windows 回收站把文件**还原到原路径**，再“刷新素材”或重新拖入原位置恢复显示；原先隐藏的仍在隐藏名单中。备份只保存记录，不能恢复磁盘文件。“撤销整理”不负责还原文件，请使用系统回收站。

## 百度 ZIP 解压与入库（1.4.0-preview.16）

下载页面中的 **ZIP 解压与入库** 有两个独立设置：**下载完成后自动解压 ZIP 并入库**、**解压并入库成功后，将原 ZIP 移至回收站**。两项默认关闭，保存后继续沿用。回收选项也用于本页手动解压；未勾选时保留原包。开启自动解压后，只处理本次批量下载内的 ZIP，按已经归好的同商品组分别创建新的解压目录，不追溯搬动历史下载。

旧版本下载记录中的 ZIP 也能手动处理：在 **下载记录** 勾选同一素材的模型包、材质包或适配包，点击 **解压所选并入库**，每次可选 1 至 100 个；单个文件也可点击 **解压并入库**。所选 ZIP 会进入同一个新目录，每个包使用独立子目录，避免同名文件相互覆盖。只将本次输出登记到素材库，无需点击全局“刷新素材”；这一步不会把素材安装到 Unity 工程。已有随机编号下载目录及原包不会为归组而搬移；原包保留时，其既有人工标题、标签、备注和来源继续保留，不被新目录覆盖。

这里只支持 ZIP；RAR／7z 暂不支持，Unitypackage 保留原文件，后续通过工程导入入口处理。本地历史解压、打开结果和重试入库不要求百度登录或联网；有下载、入库或解压任务进行时，先等待该任务结束。

在 **解压记录** 查看阶段、文件数、大小和输出目录，点击 **打开解压目录** 定位。解压或入库失败不自动回收原包；若已留下可用目录，可点击 **重试入库（保留原包）**，该重试始终保留原包。回收只在成功入库后尝试，并显示实际已回收的包；部分回收失败时，未回收文件保留，不改用永久删除。原包已回收后请通过解压记录打开结果；系统回收站的保留和恢复能力由系统及后续操作决定。

## MA 菜单预览报错怎么看

工作台的本地日志分析改进了 `ModularAvatarMenuInstaller` 已销毁引用、`MenuPreviewGUI.PushMenuInstaller` 与 `ModularAvatarMenuInstallTarget.Visit` 这类调用链的解析与中文建议。它们可指向 Inspector 菜单预览中的引用问题，不能仅凭一条堆栈判定构建或上传失败，也不能证明引用失效由哪个操作造成。建议先记录触发操作、保留工程备份，再核对失效组件和版本；不要批量删除 MA 组件。

此项只改进日志展示和排查建议，不修改第三方 MA、场景或 Prefab。第三方异常尚未在真实角色与插件组合中复现，因此不宣称已修复；列表中的历史日志或暂时没有新日志也不能代替复测。详细步骤见 [MA 菜单预览诊断说明](MA_MENU_PREVIEW_DIAGNOSTICS.zh-CN.md)。
