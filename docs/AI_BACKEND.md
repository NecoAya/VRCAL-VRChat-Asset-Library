# AI 分类与 Unity 报错解释：使用说明及实现边界

核查日期：2026-10-24。当前已实现本地主进程服务与无真实密钥测试。未进行收费 API 调用；真实账号权限、余额、网络可用性、分类准确率仍需用户配置后验证。

## 第一次使用

AI 是可选功能，默认关闭。没有 API 密钥时，本地素材整理、3D 预览和本地报错查看仍可使用。这里需要的是服务商开放平台的 **API 密钥**；网页版聊天账号或会员不代表已经具备 API 权限和可用额度。

1. 打开应用设置里的 **AI 分类与报错解释**，或从工程报错页进入 **AI 设置**。
2. 选择千问、Kimi 或 DeepSeek。点击 **打开所选服务商的密钥申请页**，在服务商自己的页面查看账号权限、收费说明和可用模型。服务商页面上的充值或购买由用户自行决定。
3. 把该服务商的 API 密钥填入密码框。模型名称可以先保留默认值；如果账号不支持该模型，再按服务商当前说明修改。此版界面不提供任意接口地址。
4. 设置 **每天最多调用次数**，默认 20 次。服装分类与报错解释共用这个次数；它限制请求数量，不是金额预算。
5. 勾选 **启用 AI 辅助**，再按需要选择 **自动补充资料库中已匹配服装的类型与风格**、**打开工程报错页后，自动解释所选工程的新错误**。两个用途分别选择，可以只开其中一个。
6. 阅读发送范围、费用和密钥保存说明，勾选 **我已了解发送范围、调用费用和本地密钥保存方式**，点击 **保存 AI 设置**。应用还需要允许联网，才会向服务商发送请求。

设置保存后无需每次输入密钥。密码框留空表示保留该服务商已保存的密钥，不会显示原值或末几位。更换服务商后，请核对模型、所选用途与密钥，再保存；请求会发往新选择的服务商，原服务商的密钥不会转发给它。每家密钥分别保存，切换服务商不等于删除旧密钥。若要删除，请切回对应服务商、保存选择，再点击 **移除密钥并关闭**。

关闭 **启用 AI 辅助** 并保存，或关闭应用联网，会停止后续请求并取消在途处理；已经到达服务商的请求可能仍被处理或计费。关闭功能会保留本机已有建议。移除密钥只移除当前服务商的本地密钥，不撤销服务商平台上的密钥，也不删除其他服务商的密钥；需要彻底撤销时，应在对应平台操作。

## 查看服装类型与风格

开启后，队列每 30 秒串行处理一件符合条件的服装。它使用已经匹配清楚的公开 BOOTH 商品资料；如果来源仍有歧义，可先在素材详情确认商品。隐藏、缺失、已回收的素材、Unity 工程，以及用户手动归到其他主分类的素材不会自动处理。

打开素材详情，在 **AI 类型与风格** 查看衣服类型、风格、判断依据、服务商、模型和生成日期。有把握不足时会显示需要核对。也可以点击 **分析当前素材**，单独尝试当前素材；可用线索不足时，结果可能为空或不确定。

建议单独保存，主分类、BOOTH 商品信息和人工标注保持各自来源。确认建议合适后，点击 **将建议加入我的标签**，才会成为可以搜索、筛选并随普通资料库备份保存的人工标签。

相同内容通常复用已有结果；队列也会记住已失败的内容，避免每次打开软件都重复请求。修正来源、更新公开说明或更换模型后可重新评估；需要主动再试时使用 **重试待处理分类**。**重新分析当前素材** 仍可能复用有效缓存，不意味着每次都会产生新的收费请求。

## 查看 Unity 报错

1. 先在工程页登记 Unity 工程，然后在报错页的 **当前工程** 中选择它。
2. 在 Unity 中打开对应工程并重现问题。页面每 5 秒检查所选工程的近期输出，也可以点击 **立即检查**。
3. 先看状态是否为 **已核对工程归属**。没有日志、归属无法确认，或输出来自其他工程时，页面会等待可核对的内容，不把全局日志直接归给当前工程。
4. 页面会合并重复错误并提供本地提示。开启 AI 报错解释后，所选工程的新错误稳定下来才合并分析；也可点击 **分析这些错误**。只增加重复次数或警告，不会反复发送相同错误。
5. 按 **已观察到的事实**、**可能原因**、**建议处理顺序** 和 **如何验证** 阅读结果。需要修改时先备份，并在 Unity 内重新执行原来出错的操作验证。应用不会执行建议里的命令，不会自动删除插件或修改工程。

自动检查只在报错页打开并选择工程时运行，不会轮流上传所有工程。离开页面再返回，同一份报错的已生成建议会在本次应用会话中恢复；重启后再次分析相同有效输入可复用服务缓存。服务忙、限流或请求取消时，页面最多间隔 30 秒重新排队 3 次；普通失败不会无限自动重试。达到每日上限后需等待下一计数日或自行调整上限。

此轮 Unity 验证使用合成日志。尚未验证用户真实工程、实际插件组合与真实 AI 服务返回的排障准确率。

## 会发送哪些内容

| 用途 | 发给所选服务商的内容 | 留在本地、不作为这项请求发送的内容 |
| --- | --- | --- |
| 服装分类 | 公开商品标题、部分公开说明、公开标签、文件名末段线索 | 完整路径、人工备注、本地预览图、贴图、模型、素材包、源码、私人交易或聊天内容 |
| 报错解释 | 有长度限制、经过过滤的错误摘要，以及必要的短版本号 | 完整日志、堆栈、完整路径、工程文件、账号会话、访问令牌 |

两种请求均使用所选服务商的 API 密钥进行认证。自动过滤会去除可识别的敏感字段，但任意插件输出的自由文本可能含有未被识别的私人信息；如不希望错误文字离开本机，可以只使用本地报错查看。此版不上传图片，3D 预览也不调用 AI。完整约定见[隐私说明](PRIVACY.zh-CN.md)。

## 接口

`src/shared/ai-contracts.ts` 是渲染进程可用的契约。主进程在 Electron ready 后创建 `new AiService({ dataDir, cipher: safeStorage })`；服务必须只存在于主进程。若包装 safeStorage，保留其方法接收者；Linux `basic_text` 存储不可用作密钥加密。

- `getState()` 返回开关、供应商、模型、当日调用数、密钥是否可用和错误状态，不返回密钥或密钥尾号。
- `updateSettings(patch)` 设置一次共用密钥与分类/诊断范围。默认全部关闭。首次启用范围需传 `consentVersion: AI_CONSENT_VERSION`；以后不重复确认同一范围。每次更改设置会取消进行中的旧请求。
- `classify({ assetId, publicTitle?, publicDescription?, publicTags?, filenameClue? }, requestId?)` 生成服装类型、风格、置信度、依据与不确定标记。
- `diagnose({ projectId, excerpt, unityVersion?, sdkVersion?, maVersion? }, requestId?)` 生成摘要、观察事实、可能原因、建议步骤、验证方式和缺失信息。
- `getClassification(assetId)` / `getDiagnostic(projectId)` 返回本地最近有效结果或 null。保存结果有独立来源记录，不修改资产主分类、人工确认或官方信息。
- `cancel(requestId)` 取消指定请求；`close()` 停止旧实例，迁移资料库或退出前调用。

运行返回 `{ ok: true, record, cached }` 或 `{ ok: false, code, message }`，失败不改变导入/装配状态。只有配置错误抛出已清理的中文错误。IPC 应验证发送窗口与资产/工程归属；由主进程从已知资产中投影公开字段，不能让网页任意构造上传内容。不要把 `AiSettings` 或其内部密钥读取方法暴露给 IPC。界面应把结果呈现为 AI 建议，不把 `risk: read-only` 当作执行授权；模型文本无任何执行通道。

## 一次设置、后台边界

`AiClassificationQueue` 接收 `{service, assets, canRun, changed, now?}`。`start()` 启动每 30 秒处理一项的队列；`stop()` 取消并等待当前请求、移除定时器，离线/迁移/退出时必须先等待它，再关闭服务。`state()` 返回运行状态、完成数、待处理数、当前商品和说明；`retry(assetId?)` 清除失败指纹后重新排队；`tick()` 允许确定性测试和调度。输入只选未隐藏、未缺失、未回收且有效分类为服装的素材，排除工程。公开 BOOTH 商品必须是 matched，且人工确认或已有明确匹配证据；自动匹配须存在规则版本、有效信号和同一商品的 metadataSourceUrl，不为 AI 再增加人工确认。手工选定其他主分类时不会进入队列。私人商城会话/购买记录不作为公开输入。

自动队列在 `ai-cache.json` 保存处理指纹（最多 10000 条），成功和失败都会记住，重启后不反复调用；仅公开内容、模型或业务空间变化才重新评估。私人备注或手工标题变化不影响指纹。达到容量上限暂停新增，避免淘汰旧失败记录后反复收费。成功结果仍受缓存容量与有效期限制；已处理标记保留到输入变化或明确重试，缓存过期不会自行形成重复收费循环。队列限额/忙碌/取消等状态不标记为商品失败。

`AI_CONSENT_TEXT` 说明供应商处理范围与费用；分类和诊断独立开关，共用所选服务商密钥和每日次数。调用计数先持久化再发请求，已预留并尝试发送的失败请求也计入，因为供应商可能计费；默认每日 20 次，可设 1–200 次，UTC 零点重置，每分钟至多 3 次、单并发。限制的是调用次数，不承诺固定人民币费用。服务层不自动重试；报错页仅对忙碌、限流、取消作有次数和间隔上限的重新排队，普通失败不循环调用。无密钥时不会寻找环境变量或其他软件的凭据。

成功结果按模型、供应商、接入地址、提示词版本、脱敏输入内容共同计算 SHA-256；相同内容复用。分类保留 30 天、诊断 7 天；版本信息变化会形成新诊断输入。缓存最多 500 条、约 3 MiB，无原始请求文字和原始响应日志。错误不缓存为成功。超时默认 45 秒（包含读取响应），支持取消；响应最多 64 KiB，拒绝截断、工具调用、额外键、越界标签与不合法置信度。

分类白名单只含公开商品标题、公开说明、公开标签、文件名末段。不会读取或上传本地预览图、贴图、模型、压缩包、源码。文件名仅是线索，没有商品内容时可能无法判断。三家有视觉能力不代表此版启用了图像上传。

诊断只保留少量包含错误标志的文本行，排除堆栈行和常见源码行；编译错误仅保留错误码及其描述。最多 20 行、总计 6000 字符，版本只允许短版本号。过滤完整路径、账户字段、Cookie、令牌、邮箱、VRChat 标识和所有 URL；不发送项目 ID。页面可以查看本地脱敏错误记录，发送前还有进一步的筛选和限长，并非逐字上传界面中的所有内容。自由文本过滤无法识别任意插件输出里的所有私人信息，不应宣称完全匿名。禁止上传整份日志或不确定归属的全局日志。日志收集、工程助手与本服务分别验收。

## 数据目录、备份、迁移

数据均放在当前用户选择的 `dataDir`：

| 文件 | 内容 | 普通备份 |
| --- | --- | --- |
| `ai-settings.json` | 开关、范围同意、模型、限额 | 不包含 |
| `ai-credentials.json` | safeStorage 加密的供应商密钥 | 必须排除 |
| `ai-cache.json` | 独立建议、输入摘要哈希、来源与队列指纹 | 不包含 |
| `ai-usage.json` | 当日次数和最近三次时间 | 不包含 |

主进程可引用 `AI_DATA_FILES` 作为同机资料库迁移白名单，使用 `AI_BACKUP_EXCLUDED_FILES` 排除普通备份的 AI 凭据、配置与派生记录。独立 AI 建议不随普通备份导出；用户明确接受并保存为人工标签的内容按现有人工标注正常备份。迁移前关闭旧服务并等待任务结束，在目标目录有冲突时遵循既有迁移策略，再用新 `dataDir` 重建实例。加密密钥依赖当前系统账户；跨电脑备份恢复不会恢复密钥，需要重新输入。损坏的设置/密钥/次数文件保留原件并暂停请求；派生缓存损坏时忽略，不把它当作可信返回。写入使用同目录临时文件后替换，不跟随目标文件符号链接。

本轮总体验收范围见[本地预览说明](LOCAL_PREVIEW_20261024.zh-CN.md)。本文新增中文内容待翻译，不能据此宣称多语言文案已经完成。

## 自定义 AI 服务商（本地开发构建）

在“设置与备份 → AI 分类与报错解释 → 服务商”选择“自定义”，再选择 OpenAI 兼容（Chat Completions）或 Anthropic Messages。填写可信服务商的 HTTPS API Base URL、实际模型 ID 和 API 密钥，并确认发送范围。OpenAI 地址填写到版本路径（例如 `https://api.example.com/v1`），追加 `/chat/completions`；Anthropic 填写域名或 `/v1`，追加 `/v1/messages` 或 `/messages`。不支持 HTTP、URL 中的账号密码、查询参数或片段；不跟随重定向。

自定义接收方将收到所选用途原有的限长文本和认证密钥，不再仅限预置三家官方域名。用户须自行核对运营方、隐私政策、费用及模型兼容性；应用不能保证代理、地域、留存或回答质量。原有用途开关、脱敏、次数限制、取消与严格结果校验保持不变，不自动测试连接或发起付费调用。

自定义密钥使用本机系统加密，并绑定 API 地址与协议；更换任一项会清除旧自定义密钥，需要重新填写和确认授权。普通备份不包含这些 AI 设置或凭据，同机资料库迁移规则保持。三家内置服务和免密钥网页 AI 入口不变，自定义仅适用于 API。未经真实服务验收，不宣称所有兼容平台均可使用。
