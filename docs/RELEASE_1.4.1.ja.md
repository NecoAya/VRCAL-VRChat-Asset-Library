# VRCAL 1.4.1 正式版

2026-11-01

Prefab の読み取り専用組み合わせプレビューと百度ダウンロードの案内

- 登録済みフォルダー、ZIP、Unitypackage、Unity プロジェクトから Prefab の階層・メッシュ・近似マテリアルを表示し、アバターと衣装の静止組み合わせにも利用できます。

- 無効なオブジェクトの子階層の非表示、静止骨格、祖先の変換を保持し、GUID・長い fileID・依存範囲・共有リソース予算の処理を修正しました。

- 百度ダウンロードの開始待機を合計45秒に統一し、失敗理由を詳しく表示します。必要に応じてアプリ内のダウンロードページを開き、ログインや認証の要求を確認できます。

- Prefab は静止外観の参考表示です。スクリプトを実行せず、Unity のシェーダー・アニメーション・MA・物理を再現しません。ネストした Prefab や組み込み形状などの未表示部分を案内し、適合は保証しません。

- 許可された場所とリソース予算の範囲で読み取り専用を維持します。実アバタープロジェクト・実アカウントでのダウンロード・認証は個別の検証が必要で、すべての百度共有のダウンロードを保証しません。

- 既存ライブラリを引き継ぎ、更新前にバックアップして旧版を終了してください。単体ファイル版は安定版の更新を確認し、フォルダー版はリリースページから手動で更新します。
