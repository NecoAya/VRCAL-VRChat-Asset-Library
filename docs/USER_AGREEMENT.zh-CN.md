## 2. 本地操作的边界

扫描、分类和商品补全以读取素材为主，整理资料单独保存。用户主动确认的工程导入会写入所选 Unity 工程；确认删除会把选定原文件移入系统回收站。百度下载页面的 ZIP 解压会另建输出目录，勾选成功入库后回收原包才会在解压、入库均成功后尝试将对应原 ZIP 移入系统回收站。隐藏仅影响应用显示，不删除原文件。请核对操作目标并保留重要工程备份；回收站和备份的可恢复性取决于系统及用户后续操作。

轻量 3D 预览在本机读取用户选定素材中的支持模型及关联资源，不改写模型、贴图、骨骼、压缩包或工程，不为预览将这些文件上传到云端。远程贴图不会因为被模型引用而自动下载。文件大小、贴图尺寸、资源范围或格式不满足限制时可能无法显示，具体以窗口提示为准。

预览用于观察形状和可读取贴图。可主动选择资料库中的另一份本地角色素材，进行角色与衣服的静态组合参考，手动调整衣服或隐藏角色部件；这些临时操作不写回原文件。它不完整还原 Unity 材质、预制件、装配、遮罩、姿势、物理和工程场景，不提供自动骨骼绑定、衣服自动适配或穿模修复。组合不代表真实试穿或适配已经完成；画面也不是素材可用性、授权或实际 VRChat 效果的认证。步骤见 [3D 预览教程](MODEL_PREVIEW.zh-CN.md)。

## 3. 登录及近期交付链接

账号浏览是可选功能。密码和验证码只在平台官方页面输入，不向维护者提交。登录并不等于同意自动读取聊天；前台链接识别及后台检查需要对应的单独确认，拒绝不会影响本地素材整理。

前台模式只处理用户在应用内打开的受支持消息／已购页面。闲鱼仅取当前打开会话的文字正文，剔除引用旧消息与输入区域；手动「检查新链接」固定使用这个前台范围，不受后台开关影响。当前后台模式按每 3 分钟一次串行检查已经加载的官方页面：闲鱼仅取有明确未读标记、唯一摘要和近期时间依据的列表预览，排除草稿替代的摘要。不会为此新建隐藏登录窗口、导航、翻页或点击其他会话。关闭所有对应窗口后不能继续发现新内容，不承诺实时或完整发现。网页自身加载可能改变平台消息的已读状态，不能承诺隐身读取。

默认按来源时间筛选最近 24 小时，可选 6／12 小时。“刚刚／N分钟前／N小时前／N天前”按显示区间最早时刻保守估算并标“约”，不声称是精确发送时刻。“今天／昨天＋时分”也标“约”并冻结首次或更早的日期推定。同账号同链接的近似时间不随轮询变新，后续完整精确证据可升级；没有可靠日期的时分只待核对，不提示为新链接。网页自身可能返回或缓存更早的记录；时间范围是应用的入库规则，不是第三方网页只会加载这些信息的保证，也不是自动删除期限。未选会话、未发现符合条件链接和账号未确认会分开提示。

## 4. 下载与交易

本应用不提供闲鱼下单、支付、代购、交易担保或自动发消息服务。闲鱼辅助搜索仅提供检索线索；交付识别用于整理用户自己有权访问的页面内容。请核实来源、卖家及使用权，不利用应用获取或传播未经许可的素材。

识别之后仍由用户选择要下载的具体文件及保存位置。程序只使用平台允许的正常网页流程，不绕过登录、安全验证、文件权限、限速、付费条件或客户端要求。文件可能失效、损坏或含有不安全内容；自动匹配不构成正版认证、安全检测或版权授权。

百度下载页可将手动勾选的 1 至 100 个历史 ZIP 作为一份素材，解压到同一个新目录；每个包使用独立子目录，避免覆盖。输出直接登记到素材库，无需全局扫描，也不自动导入 Unity。旧随机编号下载目录和原包不为归组而搬移；保留原包时，其原有人工标注保持。该操作仅支持 ZIP，不解压 RAR／7z 或 Unitypackage，不改变 BOOTH 下载流程。

**下载完成后自动解压 ZIP 并入库** 与 **解压并入库成功后，将原 ZIP 移至回收站** 默认关闭，选择会保存。自动模式只按本次批量的同商品组处理；回收选项也适用于本页手动解压。解压或入库失败时保留原包；有可用输出目录时可重试入库，重试始终保留原包。回收失败会保留未回收文件并显示实际结果，不改用永久删除。新目录、包内文件和回收结果仍需由用户核对；说明和限额不等于对压缩包安全性的完整检测。

## 8. 可选 AI 服务

AI 服装分类与 Unity 报错解释默认关闭，分别选择用途，并在启用前确认 AI 专用的发送范围、密钥保存方式和费用说明。普通联网、平台登录、链接识别同意及软件使用本身不等于同意 AI 处理。拒绝 AI 不影响本地整理、3D 预览和本地报错查看。用户可随时关闭相关用途或总开关；如处理范围实质变化，会在继续启用对应处理前要求新的确认。

用户自行选择千问、Kimi 或 DeepSeek，并在该服务商的官方平台取得 API 密钥与所需权限。请求使用用户自己的账号，服务费用、额度、可用模型及平台规则以该服务商为准。聊天会员不必然包含 API 使用权限。当前默认每天最多 20 次、可设置 1–200 次，分类与诊断共用；这是请求次数限制，不是金额上限或免费承诺。已经发送的失败、超时或取消请求仍可能产生费用。切换服务商并保存后，后续请求改用所选服务商；不同服务商的密钥分别保存在本机，不互相转交。

服装分类只发送公开商品标题、有限的公开说明、公开标签和文件名末段线索；不发送完整路径、人工备注、私人聊天、本地图片、模型、素材包或源码。报错解释只发送经过筛选、限长及脱敏的错误摘要与必要短版本号，不发送整份日志或工程。自由文本过滤无法保证识别任意插件输出中的全部私人内容；不希望这些错误文字离开本机时，可以保留本地查看并关闭 AI 诊断。具体范围和数据接收方见隐私说明。

API 密钥在资料库中使用系统加密保存；加密不可用时不退回明文。密钥仅用于向所选服务商认证，不会在正常状态接口中返回或写入普通日志、备份。用户应保管平台账号与设备；删除本机密钥不等于在服务商撤销密钥。关闭功能会保留已有建议，已经送达服务商的内容也不能通过本机取消操作撤回。

AI 输出仅作为建议，可能错误、不完整或与素材／工程实际情况不符。分类结果单独保存，不替换人工主分类、官方信息或既有人工标签；用户明确接受后才能加入人工标签。诊断建议没有命令执行或自动修复权限，不会据此改写工程、删除插件或完成安装。涉及工程修改时由用户核对、备份并验证，不以 AI 文本代替实际 Unity 操作结果。

AI 密钥、设置、调用次数及独立建议不包含在普通资料库备份中；接受为人工标签的内容按正常标注备份。通过应用进行同机资料库迁移时会迁移 AI 数据，但不同电脑或系统账户不保证能解密，恢复后可能需要重新配置。操作步骤见[AI 使用说明](AI_BACKEND.md)。

## 9. 自然语言商品发现

按描述找素材用于发现真实网站商品。AI 只生成检索词，网页搜索结果、标题命中与卖家声明不能视为原作者授权、推荐担保或适配保证。尤其是第三方卖家，用户须在原作者及平台页面核对来源、许可、适配与具体文件。搜索不会自动购买、下载、绑定本地来源或修改工程。

AI 需求整理为独立可选用途，与已有分类、诊断共同使用用户配置的额度和密钥；未启用时使用有限的本地词语规则。闲鱼后台搜索只加载正常官方搜索页，不读取聊天或绕过登录、安全验证；平台不可用时提示失败并保留其他平台结果。操作与数据范围见[找素材使用说明](AI_DISCOVERY.zh-CN.md)及隐私说明。

网页 AI 辅助不要求填写 API 密钥：点击“在应用内打开官方 AI”后，应用在当前页面嵌入所选官网，尝试填入脱敏需求、角色线索和本次随机标记，不覆盖已有草稿、不自动点击发送。用户在官网正常登录、验证和发送，服务受官网账号、额度及验证规则约束。应用只尝试读取最后一个受支持回答区；自动搜索需核对本次标记、严格结构及连续稳定，不扫描完整历史。网站改版或回答不合要求时，可使用同页手工粘贴回退。结果只作检索词，不构成商品、适配或授权证明，也不计入应用的 API 次数。各官网登录会话独立保存在已选资料库并随迁移保存，普通备份排除凭证，可从工作区清除该官网本机会话。详见隐私说明和 AI 找素材指南。

## 10. 改模工作台与装配菜单

工作台的依赖准备情况是文件线索，不构成兼容或编译通过保证。用户点击导入后才向所选 Unity 工程写入所选文件、专用助手及回执。开启菜单联动时，保留检测到的作者 MA 菜单组件；未发现时尝试创建显隐开关，与此次装配共用 Undo。该操作不自动保存场景、不自动关闭旧衣服、不修改身体形态，也不实现任意跨角色适配。

用户效果检查是手动记录，不能代替 SDK 构建、动作穿模与游戏同步验证。Unity Undo 受当前编辑会话及操作栈限制，不等于跨重启卸载；撤销场景装配不删除已导入文件。重复检查依赖本应用保留的历史，无法保证检测所有手动安装或已清理的旧记录。具体步骤及数据范围见 [工作台说明](AVATAR_WORKBENCH.zh-CN.md)。

针对 `ModularAvatarMenuInstaller` 已销毁引用及 MA Inspector 菜单预览调用链，本版只改进本地日志解析和中文排查建议，不修改第三方 MA 代码、场景或 Prefab。第三方异常尚未在真实角色与插件组合中复现，不能宣称已经修复，也不能仅凭该日志判定构建或上传失败；没有新日志不等于问题已解决。操作边界见 [MA 菜单预览诊断说明](MA_MENU_PREVIEW_DIAGNOSTICS.zh-CN.md)。

## 自定义 AI 服务商（本地开发构建）

在“设置与备份 → AI 分类与报错解释 → 服务商”选择“自定义”，再选择 OpenAI 兼容（Chat Completions）或 Anthropic Messages。填写可信服务商的 HTTPS API Base URL、实际模型 ID 和 API 密钥，并确认发送范围。OpenAI 地址填写到版本路径（例如 `https://api.example.com/v1`），追加 `/chat/completions`；Anthropic 填写域名或 `/v1`，追加 `/v1/messages` 或 `/messages`。不支持 HTTP、URL 中的账号密码、查询参数或片段；不跟随重定向。

自定义接收方将收到所选用途原有的限长文本和认证密钥，不再仅限预置三家官方域名。用户须自行核对运营方、隐私政策、费用及模型兼容性；应用不能保证代理、地域、留存或回答质量。原有用途开关、脱敏、次数限制、取消与严格结果校验保持不变，不自动测试连接或发起付费调用。

自定义密钥使用本机系统加密，并绑定 API 地址与协议；更换任一项会清除旧自定义密钥，需要重新填写和确认授权。普通备份不包含这些 AI 设置或凭据，同机资料库迁移规则保持。三家内置服务和免密钥网页 AI 入口不变，自定义仅适用于 API。未经真实服务验收，不宣称所有兼容平台均可使用。
